# Politique de sécurité

## Versions supportées

| Version | Supportée |
| --- | --- |
| `main` / dernière release | :white_check_mark: |
| Anciennes versions | :x: |

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique.**

Utilisez le signalement privé de vulnérabilité de GitHub : onglet [Security](https://github.com/ymauray/repocheck/security), puis **Report a vulnerability**.

Sont notamment concernés : une commande du skill qui pourrait modifier un dépôt sans validation, exposer un token dans le journal, ou exécuter du contenu lu dans un dépôt audité.

Décrivez le problème, les étapes pour le reproduire et son impact potentiel. Le signalement sera examiné dans les meilleurs délais, et un correctif sera publié avant toute divulgation publique.
